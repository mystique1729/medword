## Idea A: "Operating Theatre" — Brutalist Clinical

**Design Movement:** Medical Brutalism meets 1970s Hospital Signage

**Core Principles:**
- Raw, unpolished surfaces — exposed grid lines, stark contrast
- Monochrome base with single violent accent (surgical green #00FF7F)
- Information density: everything visible at once, no hiding
- Institutional authority — this is a REAL hospital, not a cartoon

**Color Philosophy:**
- Background: near-black (#0D1117) — like a darkened OR
- Primary text: clinical white
- Accent: surgical green — the one color that screams "alive"
- Warning: blood red for wrong guesses

**Layout Paradigm:**
- Asymmetric grid with exposed column lines
- Score panels as vertical strips on left/right edges
- Word display as massive centered monospaced block
- No rounded corners anywhere — all sharp 90°

**Signature Elements:**
- Monospace font for all game text (like a vital signs monitor)
- Scanline overlay effect on background
- Blinking cursor on active team

**Interaction Philosophy:**
- Keyboard-first, instant feedback
- No transitions — state changes are immediate like a defibrillator

**Animation:**
- Letter reveal: instant flash then hold (like a cardiac spike)
- Score update: number flips like a hospital pager
- Wrong guess: screen flash red for 200ms

**Typography System:**
- Display: "Space Mono" — monospaced, clinical
- Body: "IBM Plex Mono"
- All caps for labels

## Idea C: "Vital Signs" — Clinical Dark with Neon Accents ✅ CHOSEN

**Design Movement:** Modern Hospital UI meets Arcade Game Energy

**Core Principles:**
- Dark clinical base (deep navy/slate) — like a hospital at night
- Neon medical accents (cyan, green, amber) — like vital sign monitors
- Clean geometric shapes with subtle glow effects
- Serious enough to feel medical, fun enough to feel like a game

**Color Philosophy:**
- Background: deep navy (#0A1628) — authoritative, clinical dark
- Surface cards: slightly lighter navy (#0F2040) with subtle borders
- Primary accent: medical cyan (#00D4FF) — like an ECG line
- Secondary: bio-green (#39FF14) — like a heart rate monitor
- Warning/wrong: amber (#FFB800) — like a hospital alert
- Danger: crimson (#FF3B3B) — for dramatic moments
- All colors emit subtle glow — this is a live system

**Layout Paradigm:**
- Full-screen projected layout — designed for 16:9 projection
- Left sidebar: team scores as vertical "patient cards"
- Center: massive word display with ECG-line decoration
- Right sidebar: guessed letters grid
- Bottom bar: current team indicator + game-master controls

**Signature Elements:**
- Animated ECG/heartbeat line running across the top
- Glowing letter tiles that pulse when revealed
- Medical cross (+) motifs as decorative elements
- Subtle scanline texture on dark backgrounds

**Interaction Philosophy:**
- Game-master has a floating control panel (bottom of screen)
- Letter buttons glow on hover, pulse on press
- Team highlight pulses like a heartbeat when it's their turn

**Animation:**
- Letter reveal: tile flips + glows + brief particle burst
- Correct word: ECG flatline → spike → celebration
- Score update: number counts up with glow trail
- Wrong guess: tile shakes + amber flash
- Team transition: spotlight sweeps to next team

**Typography System:**
- Display: "Orbitron" — futuristic, clinical, perfect for game scores
- Body/UI: "Inter" for readability in controls
- Word tiles: "Space Mono" — monospaced for consistent tile widths
- All medical labels: letter-spacing 0.15em for clinical feel
</text>
